# Byt namn: StaffPlanner → FETCH

Allt synligt namn byts till **FETCH**:
- Webbläsarflik, delningstext och appnamn på telefonens hemskärm (index.html, manifest)
- Inloggningssidan, sidomenyn, Feedback-modulen
- Integritetspolicy, Villkor och OAuth-godkännandesidan
- Namnet som visas för externa integrationer (MCP)
- README

Oförändrat (för att inte tappa data eller bryta något):
- Webbadressen (staffplanner-fieldapp.lovable.app) – kan ändras separat om du vill
- Interna lagringsnamn för offlinedata och service worker, så sparad offlinedata i telefonerna inte försvinner
- Teststatus/testfiler

Projektminnet uppdateras med nya namnet. Efter ändringen behöver appen publiceras igen; installerade hemskärmsikoner kan behöva läggas till på nytt för att visa nya namnet.
